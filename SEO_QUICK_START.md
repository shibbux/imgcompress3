## KEY REMINDERS

1. **Never delete these files:**
   - robots.txt (search engines depend on it)
   - sitemap.xml (helps indexing)
   - .htaccess (improves performance)

2. **Check monthly:**
   - Search Console for errors
   - Analytics for traffic changes
   - Rankings for target keywords

3. **Keep updated:**
   - Privacy Policy (legal requirement)
   - Terms & Conditions (legal requirement)
   - lastmod dates in sitemap.xml

4. **Don't do these:**
   - Don't hide content with CSS (search engines can't see it)
   - Don't use keyword stuffing (will hurt rankings)
   - Don't buy backlinks (violates Google terms)
   - Don't use redirect chains (bad for SEO)
